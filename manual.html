CHAPTER 1

このアプリについて

CurtainCall は、撮影済みのカードをMac／PCに取り込み、そのまま編集ソフトのビンに並べるところまでを自動化するアプリです。挙式当日の撮って出しエンドロールのように、秒単位で編集に入りたい現場のために作りました。

やってくれること

  • カードを挿すと自動で検出し、案件フォルダの中に取り込みフォルダを作ってコピー
  • コピーした1本ずつをチェックサムで検証し、終わったら音とともに⏏ 抜いてOKを表示（Mac・Windowsとも自動でアンマウントします）
  • 同じカードを挿し直しても、前回から増えたぶんだけをコピー（都度フォーマットしない運用ができます）
  • ボタン1つで DaVinci Resolve / Premiere Pro のビンへ取り込み、続けてタイムラインまで自動生成
  • カメラの個体を自動で見分けて、Acam・Bcam のように振り分け

動作環境

項目要件
Mac Apple Silicon（M1以降）専用。Intel Macでは動きません。
〔Appleメニュー →「このMacについて」で「Apple M1」等と表示されていればApple Siliconです〕
Windows Windows 10 / 11（64bit）。WebView2ランタイムが必要ですが、Windows 11 には最初から入っています。
カメラ SONY（XAVC・a7SIII / a7IV 等）、Panasonic（LUMIX）、Canon（EOS）。
SDカード・CFexpress のどちらでも、カードリーダーの機種を問わず扱えます。
DaVinci Resolve Studio版のみ。無償版はスクリプト連携に対応していないため使えません。Python等の追加インストールは不要です。
Premiere Pro 2020（14.0）以降。連携パネルのインストールが必要です（アプリ内のボタン1つ）。
β版について

現在はβ版のため、ライセンスキーがなくても全機能が使えます。設定タブのライセンス欄は、正式版に向けた準備として置いてあるものです。

CHAPTER 2

インストール

Mac

  1. CurtainCall_0.1.3_arm64.dmg をダブルクリック
  2. 開いたウィンドウで CurtainCall を Applications フォルダへドラッグ
  3. アプリケーションフォルダからダブルクリックで起動

    Appleの公証を取得済みなので、警告なしでそのまま開きます。ターミナルでの解除作業は要りません。

0.1.1 以前をお使いだった方へ

「壊れているため開けません」と出て xattr の入力が必要だった問題は 0.1.2 で解消しました。古いバージョンはアプリケーションフォルダから削除して置き換えてください。案件・カメラの登録内容はそのまま引き継がれます。

Windows（補足）

配布zipには「インストーラ版」と「ポータブル版」が入っています。どちらか一方で構いません。

  • インストーラ版：CurtainCall_x64-setup.exe を実行。SmartScreenの警告が出たら「詳細情報」→「実行」を選んでください（コード署名がまだ無いための表示です）。
  • ポータブル版：CurtainCall.exe をそのまま実行。インストール不要です。
  • 起動しない場合は同梱の MicrosoftEdgeWebview2Setup.exe を先に実行してください（Windows 10 向けの保険。インストール時にネット接続が必要です）。
Windows 版の仕様差

ウィンドウを閉じてもアプリは終了せず、常駐します。閉じたあとにもう一度起動すると、同じウィンドウが戻ってきます。完全に終了したいときはタスクマネージャーから終了してください（終了ボタンは今後追加予定です）。

CHAPTER 3

最初の1回だけの設定

現場に入る前に、落ち着いた場所で済ませておくのが安全です。所要5分ほど。

1. 使う編集ソフトを選ぶ

「設定」タブの使用する編集ソフトで DaVinci Resolve か Premiere Pro を選びます。メイン画面の取り込みボタンのラベルが、選んだソフトの名前に変わります。

DaVinci Resolve を使う場合

Resolve 側で外部からの操作を許可しておく必要があります。既定では無効なので、必ず確認してください。

  1. Resolve の 環境設定 → システム → 一般 を開く
  2. 「外部スクリプティングの使用」をローカルにする
  3. Resolve を再起動する

    設定を変えただけでは反映されません。再起動して初めて繋がります。「繋がらない」ときは、まずここを疑ってください。

Premiere Pro を使う場合

  1. 設定タブで「Premiere Pro」を選ぶ
  2. 同じ画面の「連携パネルをインストール」ボタンを押す

    ファイルのコピーだけなので一瞬で終わります。「インストールしました」と出れば完了です。

  3. Premiere Pro を一度終了して、起動し直す

    パネルは Premiere の起動時にしか読み込まれません。起動しっぱなしでは現れません。

  4. メニューの ウィンドウ → エクステンション → CurtainCall を開く

    小さな黒いパネルに「監視中…」と出たら準備完了。編集中はこのパネルを開いたままにしてください（どこかにドッキングしておけば邪魔になりません）。一度開けば次回からは自動で開きます。

アプリを新しくした日は

CurtainCall を起動すると連携パネルも自動で最新版に入れ替わります。ただし Premiere は起動時にしかパネルを読まないので、アプリを更新した日は Premiere を一度終了して起動し直してください。古いパネルのままだと、タイムライン作成だけが効かないといった中途半端な状態になります。

2. 案件を作る

  1. 「案件」タブを開く
  2. 案件名と保存先フォルダを指定して「作成して開く」

    案件名は 2026-07-14_山田様 のように日付＋新郎新婦名にしておくと後から探しやすくなります。保存先はカード自身を指定できない作りになっています。

2件目からは「前回の設定で新規作成」が使えます。前回と同じ保存先の親フォルダを引き継いだ状態で作成できるので、現場では案件名を入れるだけで済みます。過去の案件は「最近の案件」から開き直せます。

3. カメラを登録する

初めてのカメラのカードを挿すと「新しいカメラを検出しました」と出ます。ラベル（例：Acam／手持ち／ジンバル）と色を決めて「登録して取り込み開始」を押せば、そのまま取り込みが始まります。

カメラは本体のシリアル番号で個体を識別しているので、同じ機種を2台使っていても混ざりません。カードを入れ替えても、登録は一度きりです。ラベルや色は「カメラ管理」タブでいつでも変えられます。

本番前におすすめ

使うカメラ全台で数秒ずつテスト撮影し、事前に登録を済ませておくと、当日はカードを挿すだけになります。

CHAPTER 4

当日の流れ

やることは「挿す」と「ボタンを押す」の2つだけです。

  1. カードを挿す

    自動で検出され、カメラ別のフォルダが作られてコピーが始まります。挿しっぱなしで放置して構いません。

  2. 進捗を横目で見る

    画面右下に小窓（オーバーレイ）が出ます。編集ソフトを全画面にしていても最前面に残るので、編集を続けながら状況が分かります。表示は コピー中 → 検証中 → ⏏ 抜いてOK と進みます。

  3. 音が鳴ったらカードを抜く

    完了音と⏏ 抜いてOKは「コピーと検証がすべて終わった」合図です。カードは自動でアンマウントされているので、そのまま抜けます。

    小窓は編集ソフトなど別の場所をクリックしても残ります。「DaVinci Resolveへ取り込み」を押して取り込みが終わると自動で閉じます。それ以外で消したいときは右上の × を押してください。

  4. 「DaVinci Resolveへ取り込み」ボタンを押す

    まだ編集ソフトに入れていない素材が、設定どおりのビン分けでまとめて取り込まれます。ボタンの数字バッジは、未取り込みのフォルダ数です。

    タイムライン自動生成をONにしていれば、ビンに入れたあと続けてタイムラインまで作られます。

  5. 次のカードを挿す

    以降は 1〜4 の繰り返しです。同じカードを挿し直した場合は、前回から増えたぶんだけがコピーされ、新しいフォルダに入ります。

カードをフォーマットしない運用ができます

差分コピーがあるので、現場でカードを空にする必要はありません。カードを予備の保管先として残したまま、増えたぶんだけを取り込んでいけます。フォーマットは撤収後、ご自身のカメラで行ってください。

取り込みを止めておきたいとき

画面右上の有効／無効トグルを「無効」にすると、カードを挿しても取り込みが始まりません。整理のためにカードを挿す、別案件のカードを一時的に読ませたくない、といった場面で使ってください。無効の間は画面上部に帯が出ます（戻し忘れ防止）。

CHAPTER 5

画面の見かた

本書の画面図は、アプリのUIをそのまま組み直した再現図です（サンプルの案件名・カメラ名で表示しています）。

タブできること
メイン 開いている案件名、取り込みボタン、挿入中のカードの進捗、取り込み履歴。当日はこの画面だけ見ていれば足ります。
案件 案件の新規作成、最近の案件を開く。
カメラ管理 登録済みカメラのラベル・色の変更。
設定 ライセンス、使う編集ソフト、ビンの分け方、タイムライン、トラック割り当て。

進捗の小窓（オーバーレイ）

カードを挿すと右下に現れる小窓です。カメラごとに色付きのドットとバーが並び、進捗は今回コピーする新規ぶんの合計容量に対する割合で出ます（0%から100%まで一続きに進みます）。小窓の中にも取り込みボタンがあるので、編集ソフトから離れずに送れます。

取り込み履歴

メイン画面の下に、取り込んだフォルダが新しい順に並びます。行をクリックすると選択状態になり、選んだフォルダを編集ソフトへ送り直せます（→ 第8章）。

CHAPTER 6

設定リファレンス

取り込み方法（ビンの分け方）

設定できるビン向いている使い方
すべて1つのビンに
まとめる		 Import_1、Import_2 …（押すたびに新規） 全カメラをTC順に並べて頭から拾っていく、いちばんシンプルな方式。
フォルダごとに
ビンを分ける		 取り込みフォルダと同名（Acam_1、Bcam_1 …） PC内のフォルダ構成をそのまま編集ソフトに写したいとき。同名ビンは再利用されるので増殖しません。
カメラを
グループでまとめる		 {グループ名}_1（例：Main_1 / Sub_1） 3カメ以上で「1・2カメは同じビン、3カメだけ別」にしたいとき。

「カメラをグループでまとめる」を選んだときだけ、カメラ一覧とグループ番号のボタンが開きます。グループ名を入れておくとビン名に使われ、未入力ならラベルを繋いだ名前（Acam+Bcam_1）になります。設定欄には「できるビン：Main_1 ／ Sub_1」というプレビューが常に出ているので、押す前に結果を確認できます。

新しく登録したカメラの扱い

新規カメラは空いているグループ番号（＝単独グループ）から始まります。既存のビンに黙って混ざる事故を防ぐためです。まとめたい場合は設定で番号を合わせてください。

取り込み後のタイムライン

設定内容
作らない ビンに取り込むだけ。
TC順に1本へ
並べる		 全カメラの素材をタイムコード順に、1本のトラックへ隙間なく連結します。頭から見て使うカットを拾う作業向き。
カメラごとに
トラックを分ける		 Acam→V1、Bcam→V2 …のように分け、実時間の位置に配置します。各カメラのTCが揃っている（jam sync 済み）ことが前提です。

並び順は素材の状態を見て、セット全体で1つの基準に決まります。全クリップにTCがあればTC、無ければ撮影日時、どちらも無ければファイル名の順です。婚礼が0時をまたいだ場合も正しく並ぶようになっています。

タイムライン名はベース名で、実際は {ベース名}_{番号} になります。番号はビンと共通なので、Import_3 と CurtainCall_3 のように揃います。

タイムラインが作れなくても取り込みは成功します

タイムライン生成に失敗しても、素材の取り込み自体は完了扱いです。理由が警告として表示されるだけなので、素材が入っていない、ということは起きません。

トラックの割り当て

「カメラごとにトラックを分ける」を選ぶと、カメラごとに V1 / V2 / V3 … を指定できます。映像と音声は同じ番号のトラックに入ります（Acam → V1 / A1）。

  • あるカメラで V1 を選ぶと、他のカメラは相対順序を保ったまま1つずつ後ろへ移動します（入れ替えではありません）。同じトラックに2台が乗って上書きし合う事故を、そもそも作れない設計にしています。
  • その回に使わなかったカメラのぶんは詰められます。Bcam だけ回した日は、Bcam が V1 に入ります。設定の番号は「並び順」として働きます。

ライセンス

β期間中はキーの登録なしで全機能が使えます。キーを登録すると、設定画面の最上部に「— ◯◯様」と購入者名が常時表示されます。認証は完全オフラインで、ネット接続を一切必要としません。当日の会場でWi-Fiが不安定でも、起動できなくなることはありません。

CHAPTER 7

フォルダとビンの名前

名前の付き方が分かっていると、あとで素材を探すときに迷いません。

PC内のフォルダ

案件の保存先フォルダの中に、カード1枚＝1フォルダで作られます。名前は {カメラのラベル}_{そのカメラの通し番号} です。

  • 1回目の Acam のカード → Acam_1
  • 1回目の Bcam のカード → Bcam_1
  • 2回目の Acam のカード → Acam_2

番号はカメラごとに独立して増えるので、A・Bで進み方がずれても問題ありません。同じカードを挿し直したときは、増えたぶんだけが次の番号のフォルダに入ります。

編集ソフトのビン

設定した「取り込み方法」によって決まります（→ 第6章）。1つのビンにまとめる方式では、ボタンを押すたびに Import_1、Import_2 …と新しいビンが作られます。プロジェクトパネルの一番上の階層を見てください。

CHAPTER 8

撮り込み直し・再送

ビンを作り直したい、うっかりプロジェクトを閉じてしまった、といったときのための機能です。

  1. メイン画面の取り込み履歴で、送り直したいフォルダの行をクリック

    複数選べます。もう一度クリックすると選択が外れます。キーボードでも Tab で行を選び Enter または Space で選択できます。

  2. 取り込みボタンのラベルが「選択した◯フォルダを…へ取り込み」に変わる
  3. そのまま押す

    取り込み済みかどうかに関係なく、選んだフォルダの全クリップが送られます。ビンの分け方・タイムラインは現在の設定に従います。

未取り込みが0件のときも押せます（取り込み済みフォルダの送り直しは、まさにその状況で使うためです）。「フォルダごとにビンを分ける」設定なら同名ビンが再利用されるので、何度繰り返してもビンは増えません。

CHAPTER 9

データを守る仕組み

撮り直しのきかない素材を扱うので、壊さないことを最優先に作っています。

カードには一切書き込みません

CurtainCall がカードに対して行うのは読み取りだけです。書き込み・削除・フォーマットは行いません。取り込み先にカード自身を指定することもできない作りになっています。カードのフォーマットは、これまで通りご自身のカメラで行ってください。

1本ずつ検証してから「抜いてOK」

コピーしたファイルは1本ずつチェックサムで照合しています。⏏ 抜いてOKは「コピーと検証の両方が終わった」合図です。この表示より前にカードを抜かないでください。

途中で失敗しても、そこまでは残ります

コピー中にエラーが起きても、それまでに検証できたぶんは記録に残ります。カードを挿し直せば、残りだけがコピーされます。50本中40本まで進んでいた場合、やり直しは10本ぶんです。

容量が足りないときは、始める前に止まります

コピー開始前に空き容量を確認し、足りなければ1バイトもコピーせずにお知らせします。ディスクを埋め切って編集ソフトごと不安定になる、という事態を避けるためです。

自動で取り出すのはリムーバブルメディアだけ

取り込み後の自動アンマウントは、リムーバブルと判定されたドライブに対してのみ行います。内蔵ディスクや外付けの作品アーカイブが誤って取り外されることはありません。

CHAPTER 10

できないこと

仕様として現時点でできないことです。不具合ではありません。

  • DaVinci Resolve の無償版では連携できません。Studio版が必要です。取り込みと検証だけなら無償版の環境でも使えます。
  • Intel Mac では動きません。Apple Silicon 専用です。
  • トラックの高さは自動で変えられません。Resolve・Premiere とも、スクリプトからトラック高さを操作するAPIが用意されていないためです。タイムライン左上の表示オプションから手動で調整してください。
  • Premiere ではトラックを増やせません。Premiere にはスクリプトからトラックを追加する手段が無いため、シーケンスのトラック本数が足りないぶんは配置できず、警告として報告します。あらかじめカメラ台数ぶんのトラックがあるシーケンスをお使いください。
  • AVCHD（旧Panasonic形式）は未対応です。ファイル名がリセットされる形式のため、差分判定が成立しません。
  • 撮影フォーマットの違うカメラを混ぜると、Premiere で不一致の警告が出ることがあります。スクリプト側から抑止できません。
CHAPTER 11

困ったときは

Resolve に取り込めない／繋がらない

まず「外部スクリプティング」を確認してください。Resolve の 環境設定 → システム → 一般 →「外部スクリプティングの使用」をローカルにして、Resolve を再起動します。既定では無効になっているうえ、設定を変えただけでは反映されません。ここでの詰まりがいちばん多いポイントです。

それでも繋がらない場合は、Resolve が Studio版かどうかを確認してください。無償版はスクリプト連携に対応していません。

Premiere のメニューに CurtainCall が出てこない

Premiere を再起動しましたか。パネルは Premiere の起動時にしか読み込まれません。完全に終了（Mac は ⌘Q）してから起動し直してください。

それでも出ない場合は、CurtainCall の設定画面で「連携パネルをインストール」をもう一度押してから、再び Premiere を再起動します。

「連携パネルが起動していません」と出る

Premiere 側で CurtainCall パネルが開いているか確認してください（ウィンドウ → エクステンション → CurtainCall）。パネルが閉じていると依頼を受け取れません。パネルに「監視中…」と出ていれば正常です。

「Premiereでプロジェクトが開かれていません」と出る

Premiere でプロジェクトを開いてから、もう一度取り込みボタンを押してください。

取り込みは成功と出るのに、ビンが見当たらない

プロジェクトパネルの一番上の階層を見てください。ビン名は Import_1 か、取り込みフォルダと同じ名前（Acam_1 など）です。Resolve では、直前に選択していたビンの中に入ることがあります。

タイムラインはできたが、素材が並んでいない／音声が1本しか無い

0.1.1 以降で解消済みの症状です。アプリのバージョンを確認してください。Premiere をお使いの場合は、アプリを更新した日にPremiere を再起動し忘れていないかもご確認ください。古いパネルが残っていると、タイムライン作成だけが効かないことがあります。

カードを挿しても何も起きない

次の順に確認してください。

1. 画面右上のトグルが「無効」になっていませんか（無効中は画面上部に帯が出ます）。
2. 案件を開いていますか。メイン画面の上部に案件名が出ていない場合は、「案件」タブから作成または選択してください。
3. 対応カメラのカードですか（SONY / Panasonic / Canon）。
4. そのカードに新しい素材がありますか。前回から増えていなければ、コピーするものが無いため何も起きません。

取り込み中に容量不足で止まった

コピーは開始前に止まっているので、素材は無事です。保存先ディスクの空きを確保してから、カードを挿し直してください。すでに検証済みのぶんは飛ばして、残りだけがコピーされます。

「抜いてOK」が出たのに、カードがまだマウントされている

コピーと検証は完了しているので、データは取り込めています。カードリーダーの機種によっては自動の取り出しに対応していないことがあります。その場合は Finder（Windows はタスクトレイの「ハードウェアの安全な取り外し」）から手動で取り出してください。

進捗の小窓が消えない

小窓は勝手には消えない仕様です（見落とし防止のため）。別の場所をクリックしても消えません。取り込みボタンを押して取り込みが完了すると自動で閉じます。それ以外で閉じるときは右上の × を押してください。

Windows：ウィンドウを閉じたらアプリが戻ってこない

Windows 版はウィンドウを閉じても常駐します。もう一度アプリを起動すると、同じウィンドウが戻ってきます（二重に立ち上がることはありません）。完全に終了したいときはタスクマネージャーから終了してください。

不具合の報告

β版です。おかしいと思ったことは、些細でも教えてください。次の情報があると原因にたどり着けます。

  • 使っていたカメラの機種とカードの種類
  • 画面に出たメッセージ（スクリーンショットがあると確実です）
  • Premiere の不具合なら、パネル側の表示も一緒に
  • 何をした直後に起きたか（カードを挿した／取り込みボタンを押した、など）

とくに知りたいこと

  • 取り込みの速さは実用的か
  • 通知音と画面表示は、暗い会場で分かりやすいか
  • タイムライン自動作成は、編集の入り口として使えるか
  • 迷った操作、意味が分からなかった表示
